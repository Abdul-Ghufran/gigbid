# GigSim (stand-in build)

> **Why this folder exists.** The AI-4016 starter kit (v0.1) shipped without the GigSim simulator,
> persona corpora or dev set. This is a stand-in that follows the assignment's description of GigSim
> as closely as possible. It is generated by `tools/synth/build.py` (seed 4016) and then **frozen**:
> CI verifies `gigsim/MANIFEST.sha256` so nothing under `gigsim/` changes after the freeze.
> If the official GigSim is supplied, point `GIGSIM_BASE_URL` at it — GigBid only talks to it via
> the Marketplace MCP server.

## What it simulates
| Feature | Where |
|---|---|
| Jobs: 600 dev jobs (gold-labelled), 360-job live stream released every 20 simulated minutes (duplicates, scams, planted prompt injections), 1,500 closed historical jobs for pricing statistics | `seed/jobs_*.jsonl` |
| 520 clients with public history and **hidden preferences** (must-have skills, budget ceiling, dislike of generic openings, length preference, reply propensity) | `seed/clients.json` |
| Client brain: rules (default, reproducible) or `GIGSIM_CLIENT_BRAIN=llm` | `brain.py` |
| Connects (weekly grant 80), costs by budget, idempotent writes (`Idempotency-Key`), `dry_run` | `app.py` |
| Rate limit 60 req/min/token (429 + `Retry-After`), random 503s (`GIGSIM_ERROR_RATE`, default 2%) | `app.py` |
| Policy versions incl. the **2 Nov 2026 platform policy update** (`GIGSIM_POLICY_VERSION=2026-11-02`) | `policy.py` |

## API (Bearer token per freelancer)
`GET /v1/health · /v1/policy · /v1/me · /v1/me/connects · /v1/jobs/search · /v1/jobs/{id} · /v1/clients/{id} · /v1/market/stats · /v1/proposals[/{id}] · /v1/threads[/{id}] · /v1/events`
`POST /v1/proposals · /v1/proposals/{id}/submit[?dry_run=true] · /v1/threads/{id}/messages`
Admin (`X-Admin-Token`): `POST /v1/admin/tick?minutes= · /v1/admin/reset · /v1/admin/grant_connects · /v1/admin/score`, `GET /v1/admin/outcomes`.

Dev tokens: `gigsim-dev-token-ai`, `gigsim-dev-token-web`, `gigsim-dev-token-data`.

Run: `uvicorn gigsim.app:app --port 8081`
