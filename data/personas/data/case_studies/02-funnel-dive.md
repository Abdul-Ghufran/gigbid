# Marketing funnel analysis for a DTC brand

## The problem
The store had traffic but too few visitors turned into buyers.

## What I did
- I built the core of it with Google Analytics, to make results reproducible.
- I wrote the piece that handles SQL so the system scales cleanly.
- Used turned the numbers into pictures executives read so non-technical staff could use it.

## Outcome
The work found a checkout leak worth $22k a month.
