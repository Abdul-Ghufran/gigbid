# Shopify app for bundle discounts

## The problem
The store had traffic but too few visitors turned into buyers.

## What I did
- Used liquid to make results reproducible.
- Used component-based front end so non-technical staff could use it.
- I developed the piece that handles a JavaScript server to reduce operating cost.

## Outcome
The work installed by 320 stores, 4.8 stars.

_Timeline: about 13 weeks. Client industry: ecommerce._
