# Internal admin panel for a logistics firm

## The problem
Dispatchers had no live view of where vehicles were.

## What I did
- Used React so non-technical staff could use it.
- Brought in django rest framework to keep latency low under load.
- I shipped the piece that handles a relational database so the system scales cleanly.

## Outcome
The work replaced 14 spreadsheets with one tool.

_Timeline: about 4 weeks. Client industry: logistics._
