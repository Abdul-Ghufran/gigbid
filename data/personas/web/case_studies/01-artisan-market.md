# Multi-vendor marketplace for handmade goods

## The problem
The store had traffic but too few visitors turned into buyers.

## What I did
- I built the core of it with Next.js, to reduce operating cost.
- I developed the core of it with Stripe, so the system scales cleanly.
- I built the piece that handles a relational database to reduce operating cost.
- I built the core of it with ts, to make results reproducible.

## Outcome
The work processed $180k GMV in the first six months.
