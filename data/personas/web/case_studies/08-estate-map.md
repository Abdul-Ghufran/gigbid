# Property listing platform with map search

## The problem
Buyers could not search listings the way they actually think about location.

## What I did
- I implemented the core of it with Next.js, so non-technical staff could use it.
- Brought in a relational database so the team could stop doing it by hand.
- I designed the core of it with Tailwind CSS, to keep latency low under load.

## Outcome
The work Lighthouse performance 97 on mobile.

_Timeline: about 7 weeks. Client industry: real estate._
