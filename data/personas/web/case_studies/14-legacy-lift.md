# Migration from PHP monolith to Next.js

## The problem
Pricing decisions were made without knowing how sensitive demand really was.

## What I did
- Used nextjs to reduce operating cost.
- Used ts so the system scales cleanly.
- I built the core of it with Docker, to reduce operating cost.
- Used AWS so the team could stop doing it by hand.

## Outcome
The work doubled organic traffic after the move.

_Timeline: about 14 weeks. Client industry: travel._
